Privacy policy

Last updated 8 October 2026.

nixie is self-hosted software. Each deployment is run by one owner, for that owner alone, using an OAuth client the owner registers in their own Google Cloud project. The nixie project operates no service and receives no user data.

Data a deployment accesses

With the owner's consent, a deployment may read and change the owner's Gmail, Google Calendar and Google Drive data through Google APIs, to provide assistant features to the owner, such as triaging email, managing events and working with files.

How the data is used and stored

  • Data is used only to provide features to the owner who granted access.
  • Data is stored only on hosts the owner controls.
  • Data is not sold, not shared with third parties except the AI model provider the owner configures to process requests, and not used to train general AI models.
  • The owner can revoke access at any time at myaccount.google.com/permissions, and can delete stored data from their deployment.

nixie's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
