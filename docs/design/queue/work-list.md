# The work list

This list holds every slice of the queue design once, in build order: a slice comes after each slice
in its Needs column. A slice is one pull request, or a few that ship together. Read a slice's
Follows, its Needs and its open items ahead of its build.

A deployment takes each milestone as one deploy, by
[decision record 0049](../../decisions/0049-milestone-deploys-and-the-rollback-target.md), so build
every slice of a milestone ahead of its deploy. Ahead of each deploy, the rollback check of
operations-6 starts the last release that the deployment ran on a log and a config that the release
to deploy wrote: the rollback is proven first. A rollback first removes the config keys that its
target does not know. No rollback crosses the migration of memory-index-3: the way back is a restore
from a backup. "No deploy" holds the work that ships nothing to a deployment.
[The gaps](work-gaps.md) lists the work that no slice holds, and [the open list](open.md) holds what
is not settled.
