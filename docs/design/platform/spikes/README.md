# Agent SDK spikes

Each directory here is one Agent SDK spike: a throwaway experiment that answers one question about
how the SDK behaves under nixie's options. A spike is its own Bun package with exact dependency
versions, and it installs and runs on its own. Its README gives the question, the versions it ran
against, how to run it, the output it produced, and what it left untested.

The [spikes index](../../../../research/README.md) lists these spikes with every other one.
