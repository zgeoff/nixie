# Principles

Each principle holds for every job and every deployment. Each one carries a test that shows whether
it holds. The [decision records](decisions/) apply the principles, and a link in a statement points
at the record that settles how the principle is read. The owner is you, the one person a nixie
deployment works for.

| Principle                                              | Statement                                                                                                                                                                                                                                                                                                                                                                                                    | Test                                                                                                         |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| The owner has root                                     | You can read and change every rule, and override any decision. Every rule renders as a sentence and edits through a form, under [0004](decisions/0004-rule-engine.md).                                                                                                                                                                                                                                       | Pick any refusal: you find the rule behind it and change that rule.                                          |
| Nothing is hidden                                      | nixie records every decision with the rule that made it. A request for everything returns the raw data, never a summary. The agent answers questions about memory from the stored items, under [0010](decisions/0010-memory-store.md).                                                                                                                                                                       | Ask why an action stopped: the record holds the rule and the input.                                          |
| Policy is deterministic                                | Deterministic policy is final: the same action in the same context gets the same deterministic decision. A model decides only what deterministic policy leaves open, and never overrides it. [0008](decisions/0008-auto-mode.md) sets how a model decides that grey zone.                                                                                                                                    | Replay a recorded action: every deterministic decision matches, and no model decision crosses one.           |
| Behaviour is data                                      | The system ships no persona, no jobs, and no policy for any one person. The deployment supplies all three, from a definitions source under [0020](decisions/0020-deployment.md).                                                                                                                                                                                                                             | A blank deployment has no personality and no jobs.                                                           |
| Your data stays home                                   | Readable personal data is stored only on hosts you control, in a form you can read and export. Offsite backup copies may be ciphertext on provider storage under [0032](decisions/0032-offsite-backups-and-replication.md). The principle governs storage, not processing: a model provider processes each turn, and a chat app never keeps the conversation, under [0009](decisions/0009-first-channel.md). | List every store: readable personal data stays on hosts you control; offsite backup payloads are ciphertext. |
| Untrusted content cannot reach a new destination alone | A task that reads untrusted content can send only to destinations that you, your rules or the reply target supplied, and anything else asks. The infrastructure enforces this, not the prompt: destination limits on nixie's sending tools, with the conversation always counted as untrusted, under [0015](decisions/0015-taint-scope.md).                                                                  | Plant an instruction in an email to send data to a new address: the send stops or asks.                      |
| Risk stance is set per context                         | You set how much risk each kind of job accepts. Some contexts trade risk against friction; others treat catastrophic outcomes as a separate class with their own gate. The always-ask set in [0005](decisions/0005-effects-and-taint.md) is that gate.                                                                                                                                                       | Two jobs with different stances get different decisions for the same action.                                 |
| Any model, through adapters                            | The agent runtime sits behind an adapter, and policy lives in nixie, outside any runtime. The first adapter is the Claude Agent SDK. Every action runs through nixie's own tools, under [0002](decisions/0002-approvals.md).                                                                                                                                                                                 | Swap the runtime: every policy decision stays the same.                                                      |
