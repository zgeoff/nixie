# Principles

Each principle holds for every job and every deployment. Each one carries a test that shows whether it holds.

| Principle | Statement | Test |
| --- | --- | --- |
| The owner has root | The owner can read and change every rule, and can override any decision. | Pick any refusal: the owner finds the rule behind it and changes that rule. |
| Nothing is hidden | nixie records every decision with the rule that made it. A request for everything returns the raw data, never a summary. | Ask why an action stopped: the record names the rule and the input. |
| Policy is deterministic | The same action in the same context gets the same policy decision. Model output varies; the policy decision does not. | Replay a recorded action: the decision matches. |
| Behaviour is data | The system ships no persona, no jobs, and no policy for any one owner. The deployment supplies all three. | A blank deployment has no personality and no jobs. |
| Owner data stays home | Personal data stays on hosts the owner controls, in a form the owner can read and export. | List every store of personal data: each one is on a host the owner controls. |
| Untrusted content cannot reach out alone | A task that reads untrusted content cannot send data out without approval. The infrastructure enforces the rule, not the prompt. | Plant an instruction in an email: the task has no route out to follow it. |
| Risk stance is set per context | The owner sets how much risk each kind of job accepts. Some contexts trade risk against friction; others treat catastrophic outcomes as a separate class with their own gate. | Two jobs with different stances get different decisions for the same action. |
| Any model, through adapters | The agent runtime sits behind an adapter, and policy lives in nixie, outside any runtime. The first adapter is the Claude Agent SDK. | Swap the runtime: every policy decision stays the same. |

## Open questions

- Where does the adapter boundary sit? The Claude Agent SDK is a whole harness with its own agent loop, tools, and hooks, not only a model API.
- How does nixie enforce its policy inside a runtime that has its own permission system?
