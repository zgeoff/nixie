# Anthropic report (2.1.1)

Layers: Agent SDK (local loop), Managed Agents (hosted harness), consumer (Cowork + Dispatch + computer use, Claude Code routines).

- SDK: loop in own process; transcripts JSONL ~/.claude/projects/<cwd>/; SessionStore adapter for shared storage/resume elsewhere; file checkpointing separate. Streaming-input mode queues new user messages + interrupt; single-message mode doesn't. PreToolUse hook can return `defer` -> process exits, resumes later from session (durable approvals route).
- SDK permission order (exact): hooks -> deny rules -> ask rules -> permission mode -> allow rules -> canUseTool. Hook deny holds even in bypassPermissions; hook allow doesn't skip later deny/ask. Bare allow rule or bypassPermissions approves before canUseTool ("silently bypassed"); use PreToolUse for must-run checks. dontAsk turns prompts into deny. Floor never auto-approved (rm -rf ~ class, interactive tools, org-ask connectors). updatedPermissions / localSettings writes .claude/settings.local.json. SDK default permissionMode may be auto mode -> set explicitly.
- Claude Code auto mode: classifier (Sonnet 5 default) sees user messages, tool calls, CLAUDE.md; tool results stripped. Default block list. Falls back after 3 consecutive / 20 total blocks. Chat-stated boundaries not stored as rules, lost on compaction; some blocks not clearable by approval. 0.4% FP, 17% overeager missed (engineering blog 2026-03-25).
- Managed Agents: Agent/Environment/Session/Events. Harness+model on Anthropic; tools in cloud sandbox or self_hosted worker (outbound HTTPS pull) but tool I/O flows through Anthropic control plane; not ZDR/HIPAA. user.interrupt + user.message redirect; server-stored events, no replay on reconnect (list + dedupe). stop_reason requires_action / budget_reached.
- MA permission policies: always_allow / always_ask / auto per tool; MCP default always_ask; auto denial cannot be overridden by client. Only user.message is owner intent. Each tool event carries evaluated_permission + evaluation.reason_code. Approvals = user.tool_confirmation events, never rules.
- MA memory stores: path-addressed text files at /mnt/memory/<slug>, read_only/read_write enforced by FS; 100 kB/memory, 10k/store, 8 stores/session; every change = immutable version tied to session, 30-day retention unless exported; content_sha256 precondition. Warning: injection can poison rw store. Dreaming (research preview): reads store + 1-100 transcripts, writes a NEW store (input unchanged) for review.
- Outcomes: markdown rubric, separate grader, default 3 / max 20 iterations.
- Multi-agent: coordinator one level, up to 20 defs, 25 threads; share sandbox + vault creds.
- Vaults: MCP OAuth tokens (Anthropic refreshes) + static bearer; env-var creds as placeholders swapped at egress scoped by allowed_hosts and header/body position. Not supported on self-hosted sandboxes yet.
- Budgets: list-rate pricing, pause not kill, overshoot up to one request per thread.
- Schedules (MA): POSIX cron + IANA tz, ≤9 min jitter, no backfill, auto-pause on unrecoverable errors, run record per attempt, webhooks. Routines: schedule ≥1 h, /fire API with per-routine token, GitHub events; no permission prompts at all; fire payload wrapped <routine-fire-payload> as untrusted, can't act as approval.
- Channels (Claude Code): Telegram/Discord/iMessage into an open session only; sender allowlist by pairing; anyone on allowlist can answer permission prompts.
- Cowork: cloud sandbox per session + mandatory egress proxy, or local hypervisor VM. Dispatch: one continuous thread, desktop must be awake.
- Consumer memory: Topics view/edit since 2026-07-10; shared chat+cloud Cowork since 08-25.
- Sandbox runtime (bubblewrap/seatbelt + proxy), open source sandbox-runtime; -84% prompts.
- Security: Cowork /v1/files exfil (PromptArmor, Jan 2026, egress allowlist included own upload API); "SharedRoot" Cowork VM escape 2026-07-23 (single secondary source, unverified); Claude Code repo-config RCE CVE-2025-59536, CVE-2026-21852; CVE-2026-24887 find parsing bypass; CVE-2026-39861 symlink escape (from search summaries). Computer use runs without sandbox. Background computer-use launch date unverified (third-party says 2-3 Sep).
Copy: policy in PreToolUse hook in SDK adapter, explicit permissionMode, never bare allow/bypass; hook defer + session resume for durable approvals; nixie store owns remembered rules; evaluated_permission/reason_code shape; immutable attributed memory versions (unlimited retention); dreaming-style new-store output for review; read-only memory mounts for untrusted tasks; egress secret substitution scoped by host+position; untrusted wrapper for trigger payloads; never allowlist provider upload endpoints; non-approvable floor; MA budget semantics; declarative agent files.
Avoid: non-overridable auto denials; chat-stated boundaries; hosted data; allowlist-anyone approvals; routines with no prompts.
