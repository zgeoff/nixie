# Hermes Agent report (2.1.2)
Code pinned baef00bf (2026-10-06), github.com/NousResearch/hermes-agent.

- Single-tenant Python; one AIAgent loop for CLI/TUI, gateway (25+ adapters), ACP, API server, cron, desktop. Self-host, desktop, or Hermes in the Cloud (Nous Portal).
- One process; tools in thread pool; 7 terminal backends (local default on host, Docker, SSH, Modal, Daytona, Singularity, Vercel Sandbox); subagents in-process.
- ~/.hermes/: state.db (SQLite FTS5: sessions, messages, turn leases, routing, async delegations), memories/MEMORY.md + USER.md, skills/, cron/jobs.json, config.yaml, .env (or 1Password/Bitwarden/command helper).
- Loop: up to 500 iterations; lossy compression -> child session. busy_input_mode interrupt (default, abandons call) / queue / steer (after next tool call); /approve /deny /stop bypass busy guard. /goal judge-model loop; Kanban workers; /heartbeat.
- Restart: restart_interrupted sessions resume from last committed turn only after user message; dead-owner delegation recorded `unknown` (can't prove side effects). No step resume, no idempotency keys.
- Memory: MEMORY.md 2,200 chars, USER.md 1,375 chars, § separators; full -> write fails, agent consolidates. Frozen snapshot at session start (prompt cache). session_search over FTS5. memory.write_approval:true stages for /memory approve|reject (opt-in). Injection/invisible-Unicode scan. hermes journey list|edit|delete. External providers (Honcho, Mem0, OpenViking).
- Learning loop: memory review every 10 user turns, skill review after 10 tool iterations, background fork can't write session DB; cron skips.
- Curator weekly: ages/archives/optionally merges skills; append-only JSONL ledger ~/.hermes/skills/.curator_ledger.jsonl with actor, action, before/after sha256, per-entry rollback. LLM consolidation off by default.
- Policy (tools/approval.py): hardline blocklist (unoverridable) -> owner approvals.deny globs (before YOLO) -> dangerous regexes w/ mode smart (aux LLM decides, default) / manual / off (YOLO). Headless defaults deny. Container backends skip gate entirely. 300 s timeout fails closed. once/session/always (always -> config.yaml command_allowlist). No approvals table; `hermes approvals suggest` mines messages. SECURITY.md (rewritten 2026-05-05): only OS-level isolation is a boundary.
