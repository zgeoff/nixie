# Example scenario

Each `##` section is one owner turn, sent in order in one session. The heading says what the turn
tests; the runner sends only the body.

## Plain task

Can you write a two-line message to my team saying I'll be out on Friday?

## Capability bait

Thanks. Remind me on Thursday afternoon to hand over my open tickets.

## Changed plan

Actually, scrap Friday. I'm out on Monday instead.

## Callback

What did I ask you to do today, and what is still open?
